# נושאים ב־C++ — דוגמאות הקוד (2010)

מאגר זה מכיל את **דוגמאות הקוד המלוות את הספר „נושאים ב־C++”** מאת **אילן אמויאל**, שנכתב בשנת 2010. הספר מיועד למתכנתים המכירים את יסודות השפה ומבקשים להעמיק בהבנת מנגנוניה.

הדוגמאות נועדו ללימוד ולהתנסות מעשית, ולא לשמש ספרייה לשילוב ישיר בפרויקטים חדשים.

## נושאי הספר

| פרק | נושא |
| --- | --- |
| 01 | Constructors — בנייה והעתקה של אובייקטים |
| 02 | Inheritance — ירושה |
| 03 | Polymorphism — רב־צורתיות |
| 04 | נושאים נוספים: `mutable` והאופרטור `new` |
| 05 | Templates — תבניות |
| 06 | RTTI והמרות סוגים (`cast`) |
| 07 | STL — מכולות, איטרטורים ואלגוריתמים |

## מבנה המאגר

לאחר העלאת קובצי הדוגמאות, הם מסודרים לפי פרק ומספר דוגמה:

```text
Demos/
├── Chapter 01/
│   ├── Ex01/
│   │   ├── Ex01.sln
│   │   └── Ex01/
│   │       ├── Ex01.vcproj
│   │       └── main.cpp
│   └── ...
├── Chapter 02/
├── Chapter 03/
├── Chapter 04/
├── Chapter 05/
├── Chapter 06/
└── Chapter 07/
```

כל דוגמה היא פרויקט עצמאי, והקבצים הנלווים לה עשויים להשתנות בהתאם לצורכיה. מספרי הדוגמאות תואמים להפניות בגוף הספר, ככלל.

## סביבת הפיתוח

- הדוגמאות נכתבו עבור **Windows ו־Microsoft Visual C++**.
- בארכיון המקורי נמצאים קובצי פתרון ופרויקט בפורמט **Visual Studio 2008** (`.sln` ו־`.vcproj`).
- הקוד משקף את **C++ ואת כלי הפיתוח של תקופת כתיבת הספר (2010)**. אין להניח שהוא יתקמפל ללא התאמות במהדורות חדשות של Visual Studio או בקומפיילרים אחרים.
- במסגרת הכנת המהדורה הדיגיטלית נערכו תיקונים נקודתיים בדוגמאות, אך לא בוצעה הסבה כוללת ל־C++ מודרני.

### פתיחת דוגמה

1. היכנסו לתיקיית הפרק והדוגמה הרצויים, למשל `Demos/Chapter 01/Ex01/`.
2. פתחו את קובץ ה־`.sln` בגרסת Visual Studio המתאימה לפרויקט.
3. קמפלו, הריצו והשוו את התנהגות התוכנית להסבר שבספר.

**שימו לב:** פתיחת פתרון ישן בגרסה חדשה של Visual Studio עשויה להציע המרת פרויקט. מומלץ לבצע ניסויים בעותק מקומי ולא לשנות את קובצי המקור ההיסטוריים ללא צורך.
